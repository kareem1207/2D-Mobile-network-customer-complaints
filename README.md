# Sentiment analysis of code-mixed Telugu–English mobile-network complaints

**DL_T14_2D** · Complex Engineering Problem Task 2 · Team 14 (variant 2D) · MGIT (Autonomous), Hyderabad
CM701PC Deep Learning / CM751PC Deep Learning Lab · B.Tech CSE (AI&ML), VII sem, MR-22

Team: 23261A6646 (data lead) · 23261A6655 (model lead) · 23261A6657 (evaluation & report lead)

Customers write about their mobile network in Telugu typed in English letters, mixed with English
(*"network chala bagundi but bill lo extra charges vesaru"*), often opening politely and stating the real complaint last.
This repo builds and evaluates a recurrent classifier (**negative / positive / mixed**) for such reviews with very little labelled data.

> **Honesty note — the dataset is synthetic.** No public labelled Telugu–English mobile-network corpus exists, so
> `data/code_mixed_complaints.csv` is generated by `src/generate_dataset.py` from hand-written phrase banks, with labels assigned by construction.
> The numbers below describe behaviour on this generator, **not** accuracy on real customers. Inter-annotator κ has **not** been measured
> (no second human has labelled the data yet); a blind sheet and script are provided. See `data/DATA_CARD.md`.

## What is compared
* Three recurrent layers: **SimpleRNN, LSTM, GRU** (plus BiLSTM / BiGRU as extras), 64 units, 64-d embeddings.
* Two training strategies: **from scratch** vs **initialised from an English IMDB model** of the same layer
  (recurrent weights + embeddings of words shared with the IMDB vocabulary, new 3-class head).
* Maximum sequence length ∈ {16, 32, 64, 128} and truncation side (keep first vs keep last tokens), chosen on validation data.
* Held-out phrasing: half of validation/test reviews use phrases never seen in training.
* All runs: 3 seeds, fixed random seeds, stratified train/validation/test split (2,100 / 450 / 450).

## Headline results (test split, 3 seeds)
| Layer | Start | Test macro-F1 (mean ± sd) | F1 “mixed” | s / 10,000 reviews | Params |
|---|---|---|---|---|---|
| SimpleRNN | scratch | 0.830 ± 0.011 | 0.985 | 0.47 | 56,323 |
| SimpleRNN | IMDB init | 0.834 ± 0.014 | 0.980 | 0.46 | 56,323 |
| LSTM | scratch | 0.818 ± 0.018 | 0.998 | 0.92 | 81,091 |
| LSTM | IMDB init | 0.814 ± 0.008 | 0.968 | 0.98 | 81,091 |
| GRU | scratch | 0.775 ± 0.013 | 0.926 | 0.82 | 73,027 |
| GRU | IMDB init | 0.813 ± 0.027 | 0.956 | 0.82 | 73,027 |
| BiLSTM | scratch | 0.791 ± 0.022 | 0.979 | 1.14 | 114,307 |
| BiGRU | scratch | 0.832 ± 0.020 | 0.983 | 0.87 | 98,179 |

Targets: macro-F1 ≥ 0.65 ✅ (best model 0.842) · F1 of “mixed” ≥ 0.45 ✅ (0.993, probably inflated by shortcuts) ·
10,000 predictions < 60 s ✅ (0.55 s on 4 CPU cores) · max sequence length **64** (best validation F1; 128 costs 1.8× time, no gain).

Main findings (details and discussion in the report):
* Layers are mostly within seed noise; **SimpleRNN was not worse than LSTM/GRU** here, and gradient norms decay for all three — our data does not reproduce the textbook vanishing-gradient gap.
* English IMDB initialisation: no reliable benefit (+0.004 / −0.004 / +0.038 for SimpleRNN / LSTM / GRU); only 21 % of our vocabulary overlaps IMDB.
* 92 % of the best model's errors are on **unseen phrasings** (accuracy 0.974 seen vs 0.700 unseen); negation is the weakest structure (0.66).
* Keeping the **last** tokens matters most at short lengths (validation F1 0.847 vs 0.638 at 16 tokens).

## Repository layout
```
data/        code_mixed_complaints.csv, DATA_CARD.md, ANNOTATION_GUIDE.md
annotation/  blind second-annotator sheet (210 test reviews) + annotator-A key
src/         generate_dataset.py, common.py, pretrain_imdb.py, experiments.py, kappa.py, build_notebook.py
notebooks/   DL_T14_2D.ipynb  (executed; quick run + all saved results)
results/     CSV/JSON/TXT outputs of every experiment, error list, confusion matrix
figures/     sequence-length sweep, gradient profile, confusion matrix
report/      DL_T14_2D.pdf (3-page report) and build_report.py
```

## Reproduce
```bash
pip install -r requirements.txt
python src/generate_dataset.py     # regenerates data/code_mixed_complaints.csv (seed 42)
python src/pretrain_imdb.py        # ~10 min on 4 cores; needs internet for the Keras IMDB download
python src/experiments.py          # ~25 min: sweep, 8 configs x 3 seeds, gradient profile, best model
python report/build_report.py      # rebuilds the PDF from results/
```
Open `notebooks/DL_T14_2D.ipynb` for a ~2 minute quick run plus the saved results. Results can vary slightly across TensorFlow versions
and CPUs; the numbers above were produced with TensorFlow 2.21 (CPU), Python 3.13.

## Limitations
Synthetic template data; contrastive connectors and longer length make the “mixed” class easy; word-level vocabulary cannot handle unseen spellings;
Roman-script Telugu only; no real-world validation; no TFLite/mobile deployment (not required for Task 2).
